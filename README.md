## 🚀 Key Features 
In today’s digital world, **sharing long** or **cluttered URLs**  can be inconvenient and unsafe.  
**Shrinkify** offers a modern solution to make link sharing:  

✅ Simple and fast  
✅ Secure and traceable  
✅ Insightful through real-time analytics  

By combining a **Backend Techstacks like(Node.js,Express.js,Express-rate-limiter)** with advanced **link tracking and expiry control**, Shrinkify ensures a seamless, secure, and efficient sharing experience.

---

## 📌 Project Overview  
I built the backend of **Shrinkify**, a **URL Shortener** :  

- Generate **short, unique, and shareable URLs**  
- **Track analytics** such as click counts and usage frequency  
- Allow **secure sharing**  
- Provide **expiry control** for time-limited or usage-limited URLs  

The system focuses on combining **performance**, **security**, and **usability**, ensuring users enjoy both simplicity and power in one platform.

---

## ⚡ Key Contributions  

- 🛠 **Developed a complete Backend Techstack architecture**
- ✂️ **Implemented smart URL shortening logic**, ensuring each short link maps uniquely to its original URL.  
- 📊 **Added analytics tracking**, recording total clicks, access timestamps, and device-level insights.  
- ⏰ **Built expiry-based link management**, allowing links to auto-expire after time or usage limits.   
- 🧰 **Optimized security layers** through rate limiting, input validation, and error handling middleware.
